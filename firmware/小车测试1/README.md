# 小车_手柄测试

用 **PS2 无线手柄**控制小车：**前进 / 后退 / 左平移 / 右平移，全程不旋转车体**。

从 `小车_轮子测试` 复制而来，电机方向参数（`motor_invert = {0,0,1,1}`）和接线都保留。

---

## 一、PS2 接收器接线（6 针）

接收器上那排丝印是 **CLK / CS / CMD / DAT / VCC / GND**：

| 接收器 | 接主控 | 说明 |
|---|---|---|
| **CLK** | **PB3** | 时钟，单片机输出（原定 PB2，江协板没引出） |
| **CS**（有的标 ATT） | **PA11** | 片选，单片机输出 |
| **CMD** | **PA12** | 命令，单片机输出 |
| **DAT** | **PA15** | 数据，单片机输入 |
| **VCC** | **3.3V** | ⚠️ **必须 3.3V，不要接 5V** |
| **GND** | **GND** | 共地 |

### 3.3V 从哪取

- 优先用 **TB6612 模块的 3.3V 输出**（500mA，够）
- 江协板的 3.3V（约 150mA）也能带，但同时接 OLED 会紧张

### 为什么用这几个脚

`小车_轮子测试` 里：

- **PB3** —— JTAG 的 JTDO，`Motor_Init` 里已关 JTAG（保留 SWD），可以当普通 IO
- **PA11 / PA12** —— USB 引脚，工程不用 USB（下载走 SWD / CH340），空着
- **PA15** —— JTAG 的 JTDI，`Motor_Init` 里已经关了 JTAG（保留 SWD），可以当普通 IO

## 二、手柄怎么用

| 操作 | 作用 |
|---|---|
| **START 键** | **启动 / 停止开关**（按一下启动，再按一下停止） |
| **左摇杆 上下** | 前进 / 后退 |
| **左摇杆 左右** | 左平移 / 右平移 |
| **十字键 上/下/左/右** | 备用方向键（摇杆不准时用） |
| 右摇杆 | 本测试**不用**（不做旋转） |

### LED 指示（PC13）

| LED | 含义 |
|---|---|
| 常亮 | 运行中，摇杆有效 |
| 慢闪（1 秒一次） | 已停止 |

### OLED 状态屏（新增）

| OLED | 接主控 |
|---|---|
| **VCC** | **3.3V** |
| **GND** | **GND** |
| **SCL** | **PB8** |
| **SDA** | **PB9** |

屏幕 10Hz 刷新，边开边看：

```
PS2 OK RUN B08
LX 128 LY 128
VX +40 VY  +0
A +40 B +40
```

| 位置 | 含义 |
|---|---|
| `OK` / `--` | PS2 有没有读到 |
| `RUN` / `STP` | 运行 / 停止 |
| `B08` | 按键字节 1（十六进制） |
| `LX  LY` | 左摇杆原始值，0~255，中位 128 |
| `VX  VY` | 当前命令速度 ×100（+40 = 0.4 m/s） |
| `A  B` | 轮子 A / B 的占空比 ×100 |

> 软件 I2C 刷一屏要几毫秒，所以限在 10Hz，不影响 1ms 控制循环。

上电默认是**停止**状态——必须先按一下 START 车才会动。

## 三、第一次用手柄：先配对

1. 给接收器上电（3.3V + GND）
2. 接收器指示灯**闪烁** = 正在搜索手柄
3. 给 PS2 手柄装电池，按手柄上的**电源键 / MODE 键**
4. 配对成功后接收器灯**常亮**

不同山寨手柄的配对方式不一样，常见两种：

- 短按接收器上的配对按钮，然后在 5 秒内按手柄的电源键
- 手柄按住 `MODE + SELECT` 几秒

**接收器灯不常亮 = 没配上，代码会一直判定"读不到"，车不会动。**

## 四、方向反了怎么改

在 `User/main.c` 里这两行：

```c
vx = -PS2_Axis(ps2.ly) * VXY_MAX * STICK_SCALE;   /* 上下 */
vy = -PS2_Axis(ps2.lx) * VXY_MAX * STICK_SCALE;   /* 左右 */
```

| 现象 | 改法 |
|---|---|
| 推上去车往后退 | 把 `vx` 那行的负号去掉 |
| 推左车往右走 | 把 `vy` 那行的负号去掉 |
| 前后和左右反了（推上变平移） | 把 `ly` 和 `lx` 互换 |

### 速度太快/太慢

```c
#define STICK_SCALE 0.6f    /* 摇杆打满时的速度比例，0~1 */
#define DPAD_SCALE  0.4f    /* 十字键速度比例 */
```

## 五、读不到手柄怎么查

按顺序：

| 检查 | 正常 |
|---|---|
| 接收器指示灯 | 常亮（闪 = 没配对） |
| VCC 电压 | **3.3V**（不是 5V） |
| GND | 和主控共地 |
| 6 根线顺序 | 对照丝印，别插反 |
| 线有没有松 | 杜邦线插到底 |

程序里的判断在 `PS2.c`：

```c
if (temp[1] != 0x41 && temp[1] != 0x73)
    return 0;        /* 没收到有效应答 */
```

读不到时主循环会强制 `running = 0`，车自动停下——这是防失控设计。

## 六、技术说明

- 通信方式：**软件模拟 SPI**（4 个普通 IO，约 500kHz）
- 一帧 9 个字节：`0x01 0x42 0x00 ...`，手柄应答第 2 字节是 `0x41`（或兼容的 `0x73`）
- 摇杆原始值 0~255，中位约 128，`PS2_Axis()` 归一化到 -1~+1 并加 8% 死区
- 平移用 `Chassis_Solve()` 的麦轮逆解，`wz` 固定传 **0**，所以车体不会旋转
- 加减速用 `Chassis_Update()` 的斜坡（2 m/s²），不会瞬间满速起步
